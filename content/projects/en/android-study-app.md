## Overview

Educational project built during my Computer Science degree to explore and master the fundamentals of Android development. It implements several essential patterns and components of the Android platform.

## Key Features

### Android Components

- Activities and Fragments
- RecyclerView with the ViewHolder pattern
- Intents and screen-to-screen navigation
- Services and BroadcastReceivers
- Content Providers

### Data Persistence

- Local SQLite database
- SharedPreferences for settings
- Room Database (Android Architecture Components)
- Full CRUD operations

### User Interface

- Material Design guidelines
- Responsive layouts (ConstraintLayout)
- Animations and transitions
- Light and dark themes
- Support for different screen sizes

### Architecture

- MVVM (Model-View-ViewModel)
- LiveData and ViewModel
- Repository pattern
- Basic dependency injection

## Takeaways

- Solid fundamentals of Android development
- Activity and Fragment lifecycles
- Android architecture patterns
- Mobile UI/UX best practices
- Debugging and profiling Android applications

## Educational Impact

- Foundation for more complex Android projects
- Reference for mobile development studies
- Demonstration of understanding of core concepts
- Early Android development portfolio

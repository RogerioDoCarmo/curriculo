El anuncio de lanzamiento de OmniMorse, una app traductora de código Morse para Android e iOS: escribe, habla o toca un ritmo para convertirlo en Morse, y reprodúcelo como sonido, flash, pantalla o vibración, además de aprender el alfabeto.

Construida con React Native, Expo y TypeScript sobre una arquitectura hexagonal, con Firebase Crashlytics, Storybook, GitHub Actions, CodeQL y pruebas end-to-end con Maestro — 1.363 pruebas en total. La vibración en Android necesitó su propio código nativo en Kotlin. La app ya está disponible en la App Store de iOS, y la publicación pide testers de Android para cumplir el requisito de pruebas cerradas.

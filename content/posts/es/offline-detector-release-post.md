El anuncio de lanzamiento de offline-detector, una biblioteca de código abierto que verifica el acceso real a internet mediante una pequeña solicitud de prueba, en lugar de confiar solo en la bandera online del navegador o del sistema, y lo muestra con un snackbar, banner, indicador o pantalla completa — además de un mensaje de "de vuelta en línea" cuando la conexión regresa. Un hook `useNetworkStatus` expone el mismo estado para quien quiera construir su propia interfaz.

Construido con TypeScript, React 19 y React Native 0.86 (Expo SDK 57), sin código nativo y sin dependencias como Reanimated, publicado como paquetes npm separados para su núcleo, React, web y React Native. Probado con Jest, fast-check, Playwright con axe y pruebas de mutación con Stryker, documentado con Docusaurus en tres idiomas. Todavía en la franja 0.x, así que la API puede cambiar antes de la 1.0.

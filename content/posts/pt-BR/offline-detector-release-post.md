O anúncio de lançamento do offline-detector, uma biblioteca open source que verifica o acesso real à internet por meio de uma pequena requisição de teste, em vez de confiar apenas na flag online do navegador ou do sistema, e mostra isso com um snackbar, banner, indicador ou tela cheia — além de uma mensagem de "de volta online" quando a conexão retorna. Um hook `useNetworkStatus` expõe o mesmo estado para quem quiser construir sua própria interface.

Construído com TypeScript, React 19 e React Native 0.86 (Expo SDK 57), sem código nativo e sem dependências como o Reanimated, publicado como pacotes npm separados para o núcleo, React, web e React Native. Testado com Jest, fast-check, Playwright com axe e testes de mutação com Stryker, documentado com Docusaurus em três idiomas. Ainda na faixa 0.x, então a API pode mudar antes da 1.0.
